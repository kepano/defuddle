A variable is a name that refers to a value. Once a value has a name, the rest of the program can use that name instead of repeating the value, which makes the code easier to read and to change later.

The next lesson builds on this one, so take a moment to try the exercises below before moving on. Experiment with assigning new values to the same name and printing the result each time.

Names should describe what the value means rather than how it is stored. A good name saves a comment, and a bad one can mislead every reader who comes after you, including your future self.
