Before the move, we packed the studio in five steps. Each one has a check at the end, so nothing gets left behind when the truck arrives in the morning.

1. Prepare the files.
	- Copy the source.
	- Copy the images.

	Then close the folder.
2. Read the note.

	> Keep the originals.

	Then sign it.
3. Check the sizes.

	| File | Size |
	| --- | --- |
	| notes.md | 4 KB |
	| map.png | 2 MB |
4. Pack the box.

	Label it with the date.
5. Run the script.

	```bash
	./pack.sh --all
	```

	Then check the log.

We packed everything with:

- Tape
	- Clear
	- Masking
- Boxes

The truck came at eight, and everything was on it by noon.
