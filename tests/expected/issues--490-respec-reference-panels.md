## Conformance

Every [widget](#dfn-widget) on the page needs a visible label and a role that assistive software can read.

Note 1

A [widget](#dfn-widget) that only shows an icon still needs a text label.

Note 2

A gadget inside a [widget](#dfn-widget) follows the same rule.

The rest of this section lists the levels at which a page can conform to these guidelines.

## Glossary

gadget

A part of a [widget](#dfn-widget) that a user can operate on its own, such as a button in a toolbar [widget](#dfn-widget).

widget

A control made of one or more [gadgets](#dfn-gadget), where each [gadget](#dfn-gadget) has its own label.
